# موقع ولوحة تحكم مكتب إسلام زقزوق المحامي

## الملفات
- `index.html` الموقع العام (الخدمات بتتسحب من Supabase، وطلبات التواصل بتتحفظ فيه)
- `admin/index.html` لوحة التحكم (الرابط: موقعك/admin/)
- `config.js` بيانات الربط مع Supabase
- `supabase/schema.sql` الجداول والأمان
- `logo.png` اللوجو

## أقسام لوحة التحكم
الرئيسية، طلبات التواصل، الخدمات، العملاء، القضايا، الجلسات، التوكيلات، الأتعاب، النفقات، العهد، المخزون، ملفات القضايا.

## خطوات التشغيل
1. **Supabase:** أنشئ مشروع جديد، افتح SQL Editor، الصق محتوى `supabase/schema.sql` واضغط Run. (لو شغّلت الملف قبل كده، شغّله تاني، آمن ومش هيكرر البيانات.)
2. **حساب المحامي:** من Authentication > Users اضغط Add user وأنشئ إيميل وباسورد للمحامي.
3. **قفل التسجيل (مهم جدًا):** من Authentication > Sign In / Providers أوقف "Allow new users to sign up"، لأن أي مستخدم مسجل دخول بيقدر يتحكم في كل البيانات.
4. **الربط:** من Project Settings > API انسخ Project URL ومفتاح anon (publishable) وحطهم في `config.js`.
5. **GitHub:** ارفع كل الملفات في مستودع جديد بنفس الهيكل.
6. **النشر:** من Vercel اضغط Add New > Project واختار المستودع واضغط Deploy (أو GitHub Pages). مفيش build ولا إعدادات إضافية.
